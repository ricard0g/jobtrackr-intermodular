## Tipo de proyectos que me gustan

Me motivan especialmente los proyectos que:

- Resuelven problemas reales de organización y productividad.
- Tienen que ver con datos, finanzas o toma de decisiones.
- Requieren pensar bien el modelo de datos, la API y la experiencia de usuario.
- Puedo enseñar después como parte de mi portfolio profesional.

El proyecto JobTrackr encaja en esta idea: es una herramienta para gestionar candidaturas de empleo de forma visual y ordenada.

## En qué me gustaría especializarme

A medio plazo quiero orientarme hacia:

- Desarrollo backend y arquitectura de aplicaciones web.
- Diseño de APIs limpias y mantenibles.
- Integración con servicios externos y uso de datos.

## Cómo trabajo

Me defino por:

- Aprendizaje rápido y continuo.
- Constancia y disciplina en el trabajo diario.
- Búsqueda de propósito en lo que hago (no solo “sacar la nota”).

En la práctica, esto se traduce en:

- Cuidar la calidad del código: nombres claros, separación en capas, manejo de errores.
- Usar Git y GitHub de forma profesional: monorepo bien organizado, commits descriptivos.
- Documentar lo suficiente para que otra persona pueda entender y ejecutar mis proyectos.
- Pensar siempre en cómo se verá este trabajo en una entrevista o en mi portfolio.
